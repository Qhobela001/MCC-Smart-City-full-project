## Model-improvement direction

The next detector must be developed using a controlled MCC dataset.

Priorities:

- real MCC camera footage
- accurate tight bounding boxes
- balanced class representation
- far/medium/near examples
- lighting and weather variation
- occlusion
- hard negatives
- per-class metrics
- confusion matrices
- fixed train/validation/test splits
- preserved field-test holdout set
- reproducible training configuration

Object detection should remain separate from temporal/event reasoning.

Examples:

illegal dumping =
person + waste object + tracking + placement + separation + persistence

street-cleaner activity =
person + broom + tracking + time/activity context

New model promotion must be based on MCC benchmark performance and
real-world field tests, not aggregate training mAP alone.
